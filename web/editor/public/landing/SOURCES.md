# Landing page media

The JPG files are screenshots of Pull Fiction, not reconstructed interface mockups.

- replay.jpg: a recorded Classic Era Molten Core run in the native 3D viewer, with raid frames and the raid timeline.
- plan.jpg: an empty Onyxia planning project in the native 3D editor.
- tactical-plan.jpg: a plan created from a recorded Lucifron encounter, with a 30-yard range marking.
- library.jpg: the saved-runs library containing the recorded Lucifron encounter.

Raid thumbnails are loaded from Warcraft Logs and credited in the landing footer.
