# Encounter fidelity gaps

Research completion and passing CPU state checks do not establish visual parity.
The following gaps remain visible after the boss campaign. Inspect the linked
research contracts and a qualified recording before changing behavior. A fast
kill that does not exercise a mechanic supplies no acceptance for that mechanic.

| Gap | Concrete evidence | Required next check |
| --- | --- | --- |
| Council lava height | Basin/Flame active windows are recorded. The retained lava model has below-origin geometry and depth-tested materials; the host has no recorded Z. Estimated floor placement can bury a surface. | Compare the room floor, host height, attachment offsets and surface silhouette with a recording from the same ruleset. Do not turn an arbitrary height lift into a rising/falling schedule. |
| Ground effects and destinations | Several MC/AQ/Naxx spells have authored Area or TravelEnd/Area routes that the current unit-target path omits. `SpellGoTargets.dest` is absent on this replay path. | Establish the actual destination or independently positioned hazard actor, then implement the correct native route and lifecycle. Damage-recipient positions do not establish a footprint. |
| Moam mana leech | Two SoD pulls contain 60 actual `1216501` leech records and no cast/begincast records. Current normalization drops their resource/result representation. The client supplies Impact kit264. | Preserve the raw power-transfer semantics and distinguish periodic/result dispatch before implementing it. Do not fabricate casts, current mana, damage or healing. |
| Ossirian chain appearance | Seven SoD crystal casts now use their unique same-source/spell aura recipient as the visual target. Both endpoints have recorded XY; no impact is generated. | Exercise the actual native chain with the correct client assets. A resolved endpoint is CPU evidence, not proof of its silhouette, height or cleanup. |
| Sand Trap placement | Seventeen SoD player-created traps retain target/owner identity but have no position samples. They are provider Pet records with synthetic identities. | Obtain actual hazard anchors or a qualified reference. Creator position brackets are not exact trap centers. A representative-pet fallback is not an accepted trap model. |

Template/name/instance records are not necessarily physical GUIDs. | Preserve the raw identities and obtain disambiguating lifecycle/identity evidence. A selected import can lack the preceding application entirely. | Retain the prefight observation or use a complete run. The scoped repair does not seed an absent aura, infer a duration or globally ignore snapshots. |
| Auxiliary markers and objects | Some logs contain marker/extra-ability fields that the normalized replay does not carry. Egg, crystal, shelter and other object state can be absent from combat events. | Audit the raw fields and their semantics, then add a typed consumer. An absent combat event does not prove an object or effect was absent in the real fight. |

Early SoD, SoD Onyxia/ZG and Vanilla source-only entries still need accessible
recordings. Archived metadata can establish identity while detailed events remain
unavailable. The library keeps those states separate.
